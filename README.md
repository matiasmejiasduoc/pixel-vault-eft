# Pixel Vault

Tienda de videojuegos online para la EFT de Desarrollo Frontend I.

El proyecto tiene dos carpetas:

- `vanilla`: versión con HTML, CSS, Bootstrap y JavaScript.
- `react`: versión con React y Vite.

## Cómo usarlo

### Versión vanilla

Abrir `vanilla/index.html` en el navegador.

### Versión React

```bash
cd react
npm install
npm run dev
```

Después entrar a http://localhost:5173

## Funcionalidades

- Catálogo de juegos con imagen, nombre, precio y descripción
- Filtro por categoría
- Formulario de contacto con validación
- Agregar y eliminar juegos (solo en React)
- Diseño responsive con Bootstrap
